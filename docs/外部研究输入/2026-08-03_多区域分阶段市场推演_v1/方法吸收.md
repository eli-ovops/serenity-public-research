## 2. 可复用的方法骨架

### 2.1 可证伪命题

每条研究对象先写成可结算命题，而不是主题口号：

`H =（地区，结算日期，观测指标，成立阈值，结算来源）`

命题至少包含：

- 基准事实及其数据日期；
- 一步一条的因果链；
- 必要条件与替代解释；
- 区间而非单点；
- 最强反证；
- 领先指标、失效阈值、复核日；
- 对利润池的含义；
- 从利润池到公司股东回报仍需满足的额外条件。

### 2.2 时间节点

按期限改变证据偏好，而不是把近端叙事机械外推：

| 期限 | 外部包做法 | Serenity intake 用法 |
|---|---|---|
| 约 1 年 | 预算、订单、合同、法规生效、在建项目 | 允许进入近期确认指标，但仍区分目标、义务、开工、交付、收入 |
| 约 3 年 | 已融资产能、政策路径、设备周期、采用曲线 | 要求执行里程碑和替代路径，不把制度发布当完成 |
| 约 5 年 | 人口、基础设施存量、资本形成、成本区间 | 重点转向存量利用率、维护、检测、效率和回报 |
| 约 8–10 年 | 人口/物理/已建资产与情景树 | 只保留硬约束；技术路线、企业赢家与估值不作高置信预测 |

### 2.3 证据等级

外部包的优先级与 Serenity/专项 Skill 大体兼容，但 intake 中改写为：

| 等级 | 含义 | 默认标签 |
|---|---|---|
| A1 | 法律正文、正式预算、监管原始表、国家统计原始表、SEC/法定披露、合同/订单原件 | `Confirmed`（仅确认原文实际陈述） |
| A2 | 官方机构模型、方法透明的官方预测、同行评议论文 | `Confirmed forecast`，不是已发生事实 |
| B | 行业数据库、官方/公司二次汇总、方法透明的高质量研究 | `Inferred`，需一手交叉 |
| C | 新闻、管理层观点、社交内容 | `Weak`，只能作线索或拥挤风险 |
| D | 无法追溯、截图、转述、传闻 | `Needs verification` |

证据等级只描述来源和可审计性，不等同于事件发生概率，也不自动清除 Serenity STOP gates。

### 2.4 事实、推断、条件假设、投资解释四层

每条必须拆开：

1. **事实**：原始来源在何日实际披露了什么；
2. **推断**：从事实到产业约束的最短逻辑链；
3. **条件假设**：执行、融资、价格、替代、良率、监管、客户采用等必须成立的条件；
4. **投资解释**：只描述待研究的利润池/暴露，不给公司估值、买卖、目标价、仓位或交易计划。

禁止把“算力用电上升”直接写成“某电力设备公司股东必然获利”。中间至少还要验证订单归属、供给进入速度、价格、毛利、资本开支、客户集中、现金流、稀释与估值。

### 2.5 相关性去重

- 同一政府规划、同一统计表、同一公司指引的重复报道归为一个相关性组；
- 同一锚点跨多个时间节点展开，不增加独立证据数；
- 供应链上下游若都只是转述同一终端客户，也不能算独立确认；
- 真正的交叉确认应来自不同位置、不同责任主体和不同数据生成机制。

### 2.6 可靠度与事件概率分离

- `P`：事件在指定地区、日期、阈值和结算源下发生的概率；
- `R`：当前证据和模型足以相信该概率估计的程度。

在没有历史参考类、预测分布或校准记录时，`P` 应写“未估计”，不能把 `R` 当作概率。`P=80%, R=40%` 也不能表述成“80%高置信度”。

### 2.7 时间衰减

外部包按人口/已建资产、基建/监管、宏观/贸易、技术/竞争设不同衰减率，方向正确。Serenity intake 只吸收三点：

- 远期可靠度必须下降；
- 结构锁定和执行锁定可减缓、不能消除衰减；
- 领域不能共用一个衰减速度。

包内具体权重与衰减率尚未用 100 条以上已结算预测做样本外校准，因此只能作敏感性参数，不能当经验常数。

### 2.8 领先指标、复核日与失效条件

每条外部证据卡必须预登记：

- 2–5 个可观察领先指标；
- 最强反证；
- 明确的失效阈值；
- 下次复核日期；
- 若失效，关闭、降级或转回线索池的动作；
- 若出现 materially different evidence，允许重新打开的条件。

## 3. 吸收决策

### 3.1 可直接吸收

- 可证伪命题格式；
- 基准日和数据时点登记；
- 事实/推断/条件假设/投资解释四层；
- 证据相关性分组与重复来源去重；
- `P` 与 `R` 分离；
- 领先指标、最强反证、失效阈值、复核日；
- 近端看执行、远端只保留硬约束；
- 不把宏观需求直接等同于股东回报。

### 3.2 必须改造后吸收

| 原包方法 | 必要改造 |
|---|---|
| 五级来源优先级 | 改成 A1/A2/B/C/D，并显式标记“事实”与“官方预测” |
| E/S/X/M/F/D 可靠度 | 保留维度，暂不把未经回测的权重当精确测量；增加 Serenity STOP gate 覆盖 |
| 贝叶斯更新 | 只有在参考类、似然和相关性折扣可审计时使用；否则保持定性 |
| 时间衰减 | 作为三情景敏感性，不输出单一精确值 |
| 跨市场传导矩阵 | 必须逐段验证暴露、传导率、持续性和抵消项，且对共同冲击去重 |
| “价值洼地候选层” | 改称“后续研究方向/利润池线索”；未经公司级 STOP gates 不进入候选结论 |
| 政策/需求锚点 | 增加目标→授权→义务→融资→开工→交付→收入的状态链 |
| 持续更新网页 | 固定访问日和页面版本；不把 2026-08-06 页面倒灌成 2026-08-03 的已知事实 |

### 3.3 拒绝吸收

- 任何未校准的伪精确事件概率或 Bayes factor；
- 把官方目标、需求估算、参考架构、试点或意向书当成已融资、投产、订单或收入；
- 用同源新闻数量堆叠置信度；
- 用“结构检查通过”替代事实核验；
- 从人口、电力、合规或资本开支需求直接推出公司盈利或股票回报；
- 没有最强反证、失效阈值或复核日期的高置信结论；
- 任何买卖建议、目标价、仓位、入场/退出或当前买入清单。

## 4. 与 Serenity 现有治理对照

| 维度 | 外部包 | Serenity 约束后的用法 |
|---|---|---|
| 起点 | 多区域宏观/结构锚点 | 必须转回 bottleneck-first：先物理/容量/良率/资格/电力/维护约束，再映射行业或公司 |
| 证据 | 法律、统计、公司披露优先 | 保留，并按 A1/A2/B/C/D 标记；社交只作线索/拥挤风险 |
| 预测 | 概率、可靠度、时间衰减 | 无校准则 `P=未估计`；可靠度不能清除 STOP gates |
| 公司映射 | 报告明确尚未完成 | 继续保持；如以后涉及公司，先查 `STOP-REV0`、`STOP-DEMO-NOT-PRODUCTION`、`STOP-CUSTOMER-UNCLEAR`、`STOP-CUSTOMER-CONCENTRATION`、`STOP-LINKAGE-WEAK`、`STOP-SHAREHOLDER-NOT-CAPTURED` 等 |
| 输出 | 产业利润池/价值方向 | 只能进入“后续研究队列候选”，不得自动升级 R6/R7、候选矩阵或正式结论 |
| 边界 | 不直接推荐股票 | 与 Serenity research-only 一致；继续禁止买卖、目标价、仓位、入退场和交易计划 |

## 6. 关于“0 错误 0 警告”

原包《验证报告》的“错误 0、警告 0”只表示对 66 条锚点完成了 CSV 结构、必填字段、时间节点、评分范围、URL 格式、可证伪阈值、ID 唯一性和相关性组检查。

原包同时明确披露：

- 尚未逐一下载并复算所有外部原始数据；
- 事件概率缺历史参考类校准；
- 多数区间是情景带，不是统一口径的统计置信区间；
- 尚未研究公司估值、竞争优势、资本回报、稀释与治理。

因此，“0 错误 0 警告”不是事实核验通过、不是预测准确性验证、不是 Serenity STOP gate 通过，也不是投资结论。
