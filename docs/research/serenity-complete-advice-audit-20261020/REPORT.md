# 历史买入、持有与卖出建议审计

审计日：2026-10-20。Owner：当前 Serenity 会话；早期与归档文本由同一名临时审查者辅助，最终结论由当前会话验收。研究与本地治理，不访问账户、不交易、不创建后台任务。

## 结论

**可以，这次能够定位到具体的决策故障。最主要的不是没有提前知道坏消息，而是把“公司仍有前景”反复用作持有理由，成交后没有持续执行买入前的风险约束，盈利保护与提醒也没有形成完整链条。**

这套流程目前没有证明能提高实际净收益。它具备产业研究和部分风险识别能力，却不能因此被视为已经有效的交易策略。修订的目标首先是消除已证实的决策故障；不能把规则修订宣称为已验证的收益优势。

“从来没有提醒卖出”也不符合记录：8月已建议减 CAMT、RXRX，9月17日明确建议减 TSLA、退出 FORM、减 RXRX；10月16日对前夜触发的 CLS/NVT 作了明确提醒。应审计的是**哪些风险早已知道而处置没有跟上，哪些提醒虽有但太晚，哪些已经提醒却没有成交确认**。

## 直接回答：为什么没有更早提醒抛售

### 1. 用经营失败作为卖出主条件，错过了更早的风险减仓层

一个好公司仍可能因估值、融资环境、兑现时间或拥挤而成为不合适的持仓。已有盈利也不代表继续持有的预期回报更高。

CAMT在8月已承认短期强势逻辑失败、盈利质量转弱，减过1股；但剩余仓位长期以“经营未失效”保留。INOD在10月13日已被明确描述为走势明显转弱，仍以没有经营坏消息持有2股，直到10月14日约55.55才建议减1。**不是完全没看到风险，而是没有让风险判断改变仓位建议。**

这不等于任何跌破均线都应清仓。问题在于没有事先确定：这笔交易靠什么赚钱、哪种失败要减、哪种失败要退出；短期参与失败后，又没有明确重审就使用长期故事续持。

### 2. 成交后的约束弱于成交前

| 例子 | 当时真实记录 | 审计判定 |
|---|---|---|
| INOD | 10月6日F409明确建议挂单2股改1股，2股计划风险0.92%；确认2股成交后，10月8日F411仍建议持有2股 | **确实提前提醒过。故障在成交后没有落实缩险或形成明确例外决定。** 初审漏记F409，本次纠正 |
| FORM | 9月1日F202方案92/79；用户95.89成交后，F203算出计划风险0.57%—0.60%，却仅要求停止加仓 | 已知预算偏离，没有完成持有/退出取舍；“不再买”不能消除已有风险 |
| DPC | F217只研究1股、首日不加第二股；用户说39.5买3股后F218主要登记和扩展研究 | 执行偏离未复核。但3股计划风险约0.415%，**不能错误指控已经超过0.5%** |
| CLS | F212建议280/266；用户挂282后F214明确建议改回280，并说明0.55%风险 | 属于有效事前提醒，不能说从未提示预算 |

### 3. 利润保护是下跌后补写，而不是盈利时冻结

10月15日才首次系统写齐11只的反弹减仓与走弱退出图。此前10月8、13日仍大范围给“持有、不加仓”。10月16日提醒CLS/NVT符合刚设规则，但不能反证更早的利润保护已经充分。

原日报保存的常规盘序列显示：10月6日至19日，CLS388.24→300.35（-22.64%）、NVT173.80→141.57（-18.54%）、DPC42.01→31.97（-23.90%）。这是两个固定截点间的**价格变化**，不是账户损失、最高点回撤，也不是可成交的策略回测。同期SCTX16.33→19.39（+18.74%），说明不能据此推出当时应把所有股票卖光。复算见 `root/price_path_checks.json`。

### 4. 新消息出现后撤掉旧规则，却留下风险空档

10月15日RXRX临床、合作和融资信息改变估值前提，暂停照搬旧4美元减仓条件有理由；中间回复C109已先撤销，最终F426确认。但到10月20日，新的退出图仍未完成，答复继续“暂持有”。**新信息可以改变规则，不能让风险处置无限暂停。** TSM新财报后旧419参考到期，也有类似的替代方案缺口。

### 5. 书面条件、触发核验和用户提醒不是同一件事

TSLA的358/QQQ727复合条件按留存数据在10月16日收盘成立，10月20日下一次完整行情回顾才明确提醒。记录不支持“10月19日询问被忽略”，也没有持续后台监控的送达证据。不能承诺系统会自动盯盘，又实际依赖下次聊天。

POET还有批次问题：最初减10未执行，后续“剩余仓”的退出条件又成立，但10月20日仍只重复初始减10。旧条件写的是已减后的剩余仓，不能事后声称原规则明确要求卖全20；正确做法是按用户最新确认20股，重新给出**最终希望保留多少**，避免步骤卡在未执行的第一批。

## 应保留和应否定的判断

**保留**：瓶颈研究、原始披露核验、区分融资与经营、避免报复性追涨、用整数股适配资金，以及基于集中度/估值的部分减仓。9月17日TSLA/RXRX的风险理由不会因为后来上涨就自动无效。

**否定**：“公司没坏，所以继续拿”作为充分理由；买入预算成交后自动放宽；只停加仓不处理超额风险；没有期限的“等待新图”；把研究完成、工具运行或报价覆盖当成投资效果。

9月22日对RXRX先因卖后上涨过度认错、用户安慰后又改口，暴露了评判标准不稳定。交易质量应按当时证据、预先目标、风险幅度与可执行性评判；后续涨跌是结果证据，不能单独判定原决定对错。

FORM还有模型质量问题：9月现金流模型强情景约74、昂贵区90以上；后续前瞻盈利模型基准约131、上限140。换估值方法不一定错，但必须解释股本、增长、现金转换、倍数和期限各贡献多少，不能让换模型本身制造新买点。AAON旧95上限经盈利/税率重算降到84，也应保留版本桥接。

## 本次实际修改

已将 [EXIT_DECISION_PROTOCOL.md](EXIT_DECISION_PROTOCOL.md) 纳入 [研究执行标准](../../选股研究覆盖与完成标准.md)。这次没有修改历史建议、用户成交事实、执行标准中的74家池或AGENTS中的固定九家比较基线，也没有替用户下单。

1. 每次持仓答复同时交付经营判断与风险处置：继续持有、减仓、退出或决策未完成；“没有经营坏消息”不得单独闭合持有结论。
2. 收到成交偏离，当次完成风险重算与明确处置；整数1股无法部分减时，直接比较保留和退出，不用停止加仓假装已经缩险。
3. 盈利时就记录保护条件、依据和代价。没有可靠经济依据时明确尚缺方案，不事后编造“早就应该卖”的点位，也不新加未经检验的统一百分比止损。
4. 重大新事实使旧图过期时，当次说明临时风险决定和替代图的交付期限；不能以新估值未完成无限维持持仓。
5. 全部条件以“最新确认仓位→目标剩余仓位”表达；已触发但未确认执行的建议不得因反弹自动消失，也不得当作已成交。
6. 日常先给宏观/大盘与现仓风险处置，再做新候选。74家正式池保留，报价和公告抓取不再替代现仓决策完成度。新增选股与工具扩张的暂停维持，必要持仓风险复核继续。

规则是研究流程，不等于实际止损委托。市场单不保证成交价、限价不保证成交，停止单在波动时也可能偏离触发价；不能把计划损失当作最大损失保证。[Investor.gov](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)、[FINRA](https://www.finra.org/investors/insights/stop-orders-factors-consider-during-volatile-markets)。本项目不访问或设置这些订单。

## 如何判断修改有没有用

先检验过程：是否在风险首次明确时给出处置；超预算是否同次闭环；旧图失效是否及时替换；提醒是否按时交付；未执行建议是否更新为明确目标。任何一项再犯，都能按记录定位，而不是继续写更多规则。

再检验结果：从修订后首次完整方案开始冻结逐笔建议、当时证据和期限；以同一时间起点比较原持有方案、修订方案及相关基准，计费用、未成交、跳空与卖后反弹，不挑高低点。研究建议结果与用户实际收益分开。没有固定足够样本前，不宣称“已经有效”；近期少量交易也不能可靠证明长期优势。

用户目前无需补材料才能接受本报告中的流程缺陷。只有计算**实际净收益与建议贡献**时，才需要用户主动提供成交与资金流；本项目不去查询账户。完整逐股链条见 [CASEBOOK.md](CASEBOOK.md)，原文与覆盖验收见同目录索引。
