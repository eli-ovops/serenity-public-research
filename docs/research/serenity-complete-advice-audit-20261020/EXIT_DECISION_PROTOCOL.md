# 持仓风险决定与提醒交付规则 v2026-10-20

用途：修复历史建议审计定位的执行缺陷。本文件是研究输出规则，不是经过回测证明有效的交易系统，不改变AGENTS硬门、账户访问禁令、整数股与正式74家池。历史价格、触发条件和用户成交不被本文件追溯修改。

## 第一性原理

继续持有也是一次从当前价格承担未来风险的决定。公司可能成功，不等于现价预期回报值得；成本、曾经盈利和回本愿望都不能独立证明继续持有。原始决策目标应写清：估值参与、趋势参与或明确的事件研究；不得把失败的趋势计划默默续成长期持有。

卖出有不同依据：经营论点失效、价格/趋势计划失败、估值透支、集中度或事件风险预算过大、事前期限届满。减仓不必等经营失败；业务仍成立时也不因普通波动自动清仓。仓位幅度必须从具体风险与整数约束推导，不能从“看空/看多”的形容词推导。

长期右尾参与与短期利润保护有真实代价：较紧退出可能错过大行情，较宽持有可能回吐浮盈。每笔方案只能有一个主要逻辑；若要同时保留长期参与和短期减仓，须在整数股数允许时事先划清两部分及各自规则，不能跌后才把交易仓改成长线仓。无法拆分的1股必须选择主要逻辑，说明接受的代价，不承诺两边都得到。

每次续持还要问：若今天没有这只股票，现价承担的风险是否仍值得？这是一项检验，不意味着不适合新买就自动全卖；税费、期限、已有敞口及风险预算可能造成差异，但差异必须说清。无法说明未来回报来源或与压力情景的取舍，不得仅凭成本或公司赛道维持原结论。

## 每次给用户的最小决定卡

| 字段 | 必须交付 |
|---|---|
| 事实截点 | 数据时间、交易时段、用户最后确认数量；未知成交不推断 |
| 原计划 | 投资论点、参与方式/期限、有效的估值与退出版本；初始方案找不到即写UNKNOWN |
| 经营判断 | 仍成立/受损/失效，以及当前可定位证据 |
| 风险判断 | 估值、相对强度、组合相关性、宏观及公司事件；无经营坏消息不能替代本项 |
| 本次处置 | 明确持有/减仓/退出/决策未完成；现有数量→目标剩余数量，账户未知时仅给研究层处置，不编造股数 |
| 下一条件 | 利润保护、走弱减仓、全部退出分别说明；不适用部分说明原因，整数1股不可减半 |
| 失效/期限 | 新事实会使哪一部分过期、何时复核；条件已触发与仅预警分别标明 |
| 提醒状态 | 本次已交付；下次何时才能核验。无后台系统不得称会自动提醒 |

没有闭合风险判断时，不能仅凭经营成立输出无条件“可以继续持有”。如果不得不保留临时意见，明确持续承担何种风险、补哪项证据、谁负责、截止何时；不得把临时意见重复当完成。

## 成交偏离：当次处理

仅接收用户主动提供的信息，不访问账户。实际价/数量与原建议不同，当次重算名义金额、合并相关敞口、至原固定失效的计划损失及预算。当前资金未知则标账户层未验证，不能沿用过期净值冒当前事实。

- 超预算或违反原方案：比较缩到原目标与继续持有的风险；给出明确研究建议、依据及待用户决定的实质差异。需要具体交易例外时不得默认为用户已经接受。
- 仅1股无法部分减：直接面对持有或退出取舍；不得用“今后不加”表示已修复风险。
- 数量偏离但预算仍通过：如DPC三股案例，不能错误称超限，仍需复核原首日限制和其他挂单最坏同时成交风险；不读取或推断订单状态。
- 不为适配已成交价格任意移动失效位；经营证据确实改变时按版本更替处理。

## 盈利保护：在盈利时就写，不等跌后补

每次完整持仓复核检查：现价是否已消耗基本面上修空间，风险收益是否明显变差，是否持续落后匹配行业，宏观风险与相关敞口是否上升。选择持有或减仓都要有具体理由；不要求顶点预测，也不要求每次上涨兑现。

对拟继续持有的盈利仓，给有依据的走弱/估值/期限条件、若提前卖出可能失去的上涨敞口及跳空风险。没有可辩护阈值就说明方案尚未完成，不能随手添加统一回撤%、均线或目标价，也不能把旧经验阈值宣称已验证。

## 重大新事实：替换规则，不暂停全部风险管理

财报、融资、临床、并购或指引改变原假设时，列出旧图哪项过期、哪项仍可用、对风险和估值的双向影响。本次报告必须给临时处置与新图的有限交付期限：原则上在下一次常规盘前完成；若信息发布时间使此期限不可行，写明具体时刻及临时风险决定。

到期后第一次回报必须交付替代图，或明确“风险研究未完成/管线故障”与处置建议；不得原样“暂持有、等重估”。没有新图不等于恢复已失效旧图；也不等于所有仓位自动安全。

## 触发、未执行与提醒

1. 判定盘中/收盘/事件条件时严格使用原定义，不把盘中低点当收盘、不把盘后当常规盘。
2. 条件成立后记录首次可核验时刻、本次告知时刻、证据与目标剩余数量。普通反弹不自动取消；新事实使规则失效则明确新旧桥接与代价。
3. 以用户最新确认仓位计算目标，未确认的旧建议不视为成交。先减10后再减10的流程不能因第一批未执行而漏掉最终风险决定；也不能把仅适用剩余仓的旧规则事后扩大成全仓指令。
4. 每张决定卡清楚写下下一次条件，避免用户只能等下一次问“今天怎么样”才知道方向。本项目当前只有按请求复核，**没有持续监测与自动推送**，不得说“触发时我会自动提醒”。不创建scheduler、服务或监控。
5. 写出的条件只是研究建议。计划价差不保证实际最大损失；成交、未成交、跳空与费用分别记录，不承诺某个止损价必能卖到。

## 模型变更与日常顺序

- 模型上限改变时，列旧值/新值、适用期限、数据增量和方法变化。经营增长、股数、利润/现金转换、估值倍数分别桥接；仅因DCF换PE不能声称经济价值已被证明提高。
- 日常先简明核QQQ/VIX、宽度及重大宏观，再交付全部最新确认持仓的风险决定，随后处理新候选。固定74家覆盖仍按原标准，报价获取量不得充当逐股决定完成数。
- 暂停新增选股与工具扩张期间，保留必要持仓风险复核；不以暂停研究为由建议清仓。工具、社媒和更多财报不替代清楚的决定与交付。

## 验收与效果验证

当轮通过条件：事实与成交分离；有效规则适用于对应仓位；已触发项明确处置；预算偏离同次闭环；新图替换有期限；未完成不伪装持有完成；没有自动提醒假承诺。

未来效果单独观察，冻结原始建议而非事后改写。记录错过上涨、假突破损失、卖后反弹、跳空、未成交、费用，与同起点简单持有及匹配基准比较。实际成交收益与研究方案表现分别报告，样本不足不宣布策略已有效。过程规则合格是必要条件，不是盈利证明。
