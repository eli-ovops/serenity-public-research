## 优先结论

1. **先补决策状态与退出闭环，再谈多智能体。** 上游 TradingAgents v0.6.0 已支持可选 `PortfolioContext`，能区分“未提供持仓”与“空仓”，并把持仓注入交易员/风险经理提示；其记忆结算将单次建议按固定持有天数与基准比较。两者仍不等于 Serenity 的用户确认成交、逐批实际股数、旧图到期、新事实重估、退出触发与实际净收益。当前本地桥接仅是 Codex LLM/工具转换及冻结公开证据分发，README 记载的 15 次模型/24 次工具完整图运行**验收失败**，不能宣称策略生效。[上游持仓源码](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/portfolio.py)；[记忆结算源码](https://github.com/TauricResearch/TradingAgents/blob/e8f5503e9b86d5c2710b0c76b1f686703968c9df/tradingagents/memory/settlement.py)；本地 `tools/tradingagents_codex/README.md`、`bridge.py`、`evidence_adapter.py`。
2. **一手披露的时间可用性必须独立于财报期。** edgartools 可以定位 SEC 10-K/10-Q/8-K、XBRL 财务指标和 8-K 附件，但本地设计仍需保存 accession、提交/可见时间、原始披露片段、指标单位/期间/修订版；`null` 与解析失败留缺口，不能回填未来披露。8-K Item 2.02 的 EX-99 表有时早于 10-Q；并非所有 8-K 有可解析表格。[README](https://github.com/dgunning/edgartools/blob/c2987cc11090971256aa3c5ffd399eb9b07df470/README.md)；[8-K 官方项目文档](https://github.com/dgunning/edgartools/blob/c2987cc11090971256aa3c5ffd399eb9b07df470/docs/eightk-filings.md)；[财务指标实现](https://github.com/dgunning/edgartools/blob/c2987cc11090971256aa3c5ffd399eb9b07df470/edgar/financials.py)。
3. **回放用可得时点和订单语义验收，而非“历史命中率”。** qlib 的滚动任务按测试起点截断训练/验证段、PIT 运算拒绝引用未来期间；skfolio `WalkForward` 提供连续测试区间和 `purged_size`。订单回放需要下一可交易时点、跳空、限价未成交、费用/滑点；backtrader 源码和 Lean FillModel 都提供可核读参照。它们本身不保证输入数据干净、回测无选择偏差或有 alpha。[qlib 滚动任务](https://github.com/microsoft/qlib/blob/54355232463878d2eebb91fe0ee5fa7fa1f5976c/qlib/workflow/task/gen.py)；[PIT 运算](https://github.com/microsoft/qlib/blob/54355232463878d2eebb91fe0ee5fa7fa1f5976c/qlib/data/pit.py)；[skfolio walk-forward](https://github.com/skfolio/skfolio/blob/adc006909df43a854da8406ca5d79335e286f652/src/skfolio/model_selection/_walk_forward.py)；[backtrader broker](https://github.com/backtrader/backtrader/blob/b853d7c90b6721476eb5a5ea3135224e33db1f14/backtrader/brokers/bbroker.py)；[Lean FillModel](https://github.com/QuantConnect/Lean/blob/61c598b66ed8051d156bba10001eab4f3e86bcb9/Common/Orders/Fills/FillModel.cs)。

## 给主 PRD 的落地验收条款

- **数据契约**：每条财报、X 线索、行情、公司事件都有 `source_url`/原文哈希、`published_at` 或 SEC `filed_at`、`retrieved_at`、交易时段和 `known_at`；`known_at > decision_at` 必须拒绝进入该时点决策。X 只当线索，未获公司/监管一手确认不得自动解除硬门。财报解析为 `UNKNOWN` 时保留缺口和原始附件，不用二手摘要填值。
- **决策状态**：按用户主动确认构建“持仓数量/成本/确认时间/未确认建议”快照；未知与零分开。建议输出 `继续持有/停止加仓/减仓/退出`、依据、触发、失效、到期、下一复核时点及目标剩余整数股，且成交未确认不改账。输入或新财报/事件发生变化时旧图到期，输出替代决定或明确 `研究未完成`。这些均为研究文件状态，不连接券商。
- **回放与评价**：先冻结规则、样本池、基准和已知时间，再做逐日 walk-forward。信号与可成交 bar 分开；费用、滑点、跳空、限价未成交、部分成交及公司行为为必测；同时呈现原始收益、扣成本收益、基准差、最大回撤、尾部/相关风险、未决定日和失败样本。决策级固定持有天数评分与用户实际收益分列；缺成交/现金流时实际净收益 `UNKNOWN`，不得拿模型回测替代。
- **最小构建取舍**：先实现公开证据包 + 持仓/建议状态机 + 新事实到期 + 可得时点回放的轻量原型和审计报告；仅在它们能过案例验收后考虑多 agent 扩张、框架引入或任何收费数据。所有执行仍保持 Serenity research-only。
